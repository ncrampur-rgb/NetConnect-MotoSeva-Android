NetConnect + MotoSeva Mobile V12

No APK required. Upload the CONTENTS of this folder (index.html, logos, manifest.webmanifest, sw.js) to an HTTPS static web host such as GitHub Pages or Netlify. Then open the HTTPS address in Android Chrome. Chrome menu > Add to Home screen. After first online visit, app shell can load offline. CSV must be imported on each browser separately. Bills are saved only in that browser; export JSON backup regularly. Clearing site data deletes locally stored bills. Do not publish real customer data in the public repository.

For GitHub Pages: repository Settings > Pages > Deploy from a branch > main / root > Save. GitHub Pages websites are public even if source is private; do not upload customer records.

4x6 printing depends on mobile print dialog/printer support. Large India PIN CSV may exceed localStorage limits. No automatic device sync or server backup.
